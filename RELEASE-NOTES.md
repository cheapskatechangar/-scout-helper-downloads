# Portable 3.1.1

Created by CheapskateChangar. Released 2026-09-13.

- Website logo embedded beside the desktop title, available offline.
- Two-file ZIP: BAT launcher and PowerShell application.
- Start, Pause, Resume, Stop, window selection, selected permission labels, and run limits.
- Optional AI enhancement with one follow-up message and a default cap of three user-confirmed handoffs.
- Detect only and permission settings remain independent of AI enhancement.
- Includes the earlier status-file sharing fix.

Automatic completion detection and chat sending are not implemented. Follow-ups use manual copy/send. This is a pilot build; native Windows acceptance remains pending. See the README for setup, scope, and validation details.

This public repository distributes the existing 3.1.1 package unchanged. Its SHA-256 matches the development release. No development history or run logs are included.
